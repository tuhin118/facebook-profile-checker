# Facebook Profile Checker

Node.js + Express দিয়ে বানানো Facebook প্রোফাইল চেকার।

## ডিপ্লয় করার নিয়ম

১. GitHub-এ রিপোজিটরি ফর্ক বা ক্লোন করুন
২. Render.com এ গিয়ে "New Web Service" সিলেক্ট করুন
৩. GitHub রিপো কানেক্ট করুন
৪. Build Command: `npm install`
৫. Start Command: `npm start`
৬. Environment Variables যোগ করুন:
   - `API_MARKET_KEY` = আপনার RapidAPI কী
   - `API_MARKET_HOST` = facebook-profile-checker.p.rapidapi.com
   - `API_MARKET_URL` = https://facebook-profile-checker.p.rapidapi.com/check
৭. Deploy চাপুন
